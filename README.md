## Tujuan
Menerapkan manipulasi DOM, event listener, perubahan class CSS, penghitung karakter, validasi form workshop, dan To-do List.

## Struktur folder
- `index.html` — struktur halaman
- `style.css` — tampilan responsif
- `script.js` — interaksi dan validasi
- `screenshots/` — ilustrasi dokumentasi

## Cara menjalankan
1. Buka folder `Lab6Web` di Visual Studio Code.
2. Buka `index.html` di browser atau gunakan ekstensi Live Server.
3. Uji tombol, penghitung karakter, dropdown sesi, validasi form, dan To-do List.
4. Tekan F12 lalu buka Console untuk memeriksa kesalahan.

## Fitur
Manipulasi teks, event click, `classList.toggle()`, penghitung karakter dengan event input, validasi nama minimal 3 karakter/email/sesi, event change, ringkasan pendaftaran, reset form, To-do List tambah/selesai/hapus, dan tombol tampil/sembunyikan paragraf.

## Pengujian validasi
- Kolom kosong atau nama kurang dari 3 karakter: ditolak.
- Format email tidak valid: ditolak.
- Sesi tidak dipilih: ditolak.
- Semua input valid: pesan sukses dan ringkasan ditampilkan.
